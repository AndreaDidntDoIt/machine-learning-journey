# Logistic Regression

## Objetivo

Implementar un modelo de Regresión Logística para resolver un problema de clasificación binaria utilizando Python y Scikit-learn.

## Dataset

**Diabetes Dataset**

El objetivo es predecir si un paciente presenta diabetes (1) o no presenta diabetes (0) utilizando características médicas como:

- Pregnancies
- Glucose
- BloodPressure
- SkinThickness
- Insulin
- BMI
- DiabetesPedigreeFunction
- Age

## Conceptos aprendidos

- Aprendizaje supervisado
- Clasificación binaria
- División de datos en entrenamiento y prueba
- Regresión Logística
- Predicciones con `predict()`
- Probabilidades con `predict_proba()`
- Evaluación mediante:
  - Accuracy
  - Confusion Matrix
  - Classification Report

## Resultados

El modelo fue evaluado utilizando un conjunto de prueba del 30% de los datos.

## Conclusiones

La Regresión Logística permite clasificar pacientes según la probabilidad de presentar diabetes. La evaluación del modelo permite identificar sus aciertos y errores mediante diferentes métricas.
